# 3D Cricket Prototype

This is a beginner-friendly Unity cricket starter built for Unity 6.3 LTS `6000.3.4f1`.

## Open it

1. Open Unity Hub.
2. Click **Add project from disk**.
3. Select this folder: `C:\Users\shiva\OneDrive\Documents\New project`.
4. Open the project with Unity `6000.3.4f1`.

## Build the starter scene

When Unity finishes compiling:

1. Open the top menu: **Cricket Prototype > Build Starter Scene**.
2. Open `Assets/Scenes/CricketPrototype.unity` if Unity does not open it automatically.
3. Press **Play**.

## Controls

- `Space`: bowl
- `Q` / `E`: adjust bowling line
- `Up Arrow` / `Down Arrow`: adjust pace
- `J`: drive shot
- `K`: defensive shot
- `L`: lofted shot
- `I`: pull shot
- `O`: cut shot
- Hold `A` / `D` or `Left Arrow` / `Right Arrow`: place the shot
- `R`: reset the match

## What is already included

- A generated 3D pitch and outfield
- Ball physics and bounce
- Bowler delivery system
- Bat collision and timing-based shot power
- Basic wickets
- 4/6 boundary scoring
- Simple run estimation
- One-over score tracking
- Follow camera and on-screen controls
