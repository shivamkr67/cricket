# Force Apply Updates In Unity

If the game still looks old in Unity, the editor is showing the old scene from memory.

## Do this exactly

1. Stop Play mode.
2. Click `Assets > Refresh`.
3. Wait until Unity finishes compiling.
4. Click top menu `Cricket Prototype > FORCE APPLY MAY 06 UPDATES`.
5. Unity will open `Cricket_50_Marks_Final`.
6. Press Play.

## What you should see

- `Oval Outfield`
- `Outer Oval Wall`
- `Oval Boundary Rope`
- `Lower Seat Ring`
- `Upper Seat Ring`
- `2 OVER OVAL STADIUM` text on the pavilion

## If it still does not change

Close Unity completely, reopen the project, then double-click:

- `Assets/Scenes/Cricket_50_Marks_Final.unity`
